GitHub Pages

GitHub Pages permite publicar nuestra página web y acceder a ella desde Internet.

¿Cómo se ha publicado?

1

Crear el proyecto

Se crea la página web utilizando HTML y CSS.

2

Subir el proyecto a GitHub

Los archivos del proyecto se suben a un repositorio de GitHub.

3

Configurar GitHub Pages

Desde Settings → Pages seleccionamos la rama main y la carpeta raíz.

4

Publicar

GitHub genera automáticamente una dirección web para acceder al proyecto.
